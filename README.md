# Postly

A social blogging mobile application built with **Kotlin and Jetpack Compose**.

## Backend

Postly uses a RESTful backend API built with **Node.js, Express, and MongoDB**.

**[Postly Backend Repository](https://github.com/bavlysafwatt/postly-backend)**

The backend repository contains the API, database integration, authentication, and server-side logic used by the mobile application.
